الحكم

في وضع SPA الـ document بيبقى متاح في المتصفح — فـ bug الـ SSR بيروح. ده معناه نظرياً ممكن نستخدمه. لكن معناه معمارياً غلط: البانل control panel بـ 17 شاشة ثابتة، مش app builder. الـ lowcode هيدّي 30 ملف runtime و IndexedDB و Excel export من غير فايدة. والباكدج 2.2.0 ما بيذكرهوش.

القرار: لا نستخدمه. الحزمة تبقى زي ما هي للـ ERP apps. البانل يبني بـ Quasar components صرفة حسب تصميمه.

6. الـ checklist من الباكدج

  • dist/spa مفيهوش CLAN_DIR ولا توكن ولا مفتاح
  • الـ backend مربوط على loopback
  • الـ proxy بيوجّه /api/ بس للـ backend
  • بيانات غلط بترفض واللوجز مفيهاش credentials
  • أوامر عشوائية وأسماء أجهزة غير متحقق منها بترفض
  • الـ API errors مفيهمش raw stderr ولا stack ولا paths
  • HTTPS و firewall و rate limiting موثّقين
