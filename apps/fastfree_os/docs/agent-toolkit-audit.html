2. Antigravity — شغّلته فعلاً

الـ binary موجود في ~/.local/bin/agy (Antigravity CLI 1.3.3). Herdr بيسجله كـ agent مدعوم (kind = agy). فتحت workspace جديد باسم clan-panel-agy وبدأت فيه agent جديد.

  1. herdr workspace create --label clan-panel-agy
    رجع workspace_id = wK مع pane wK:p1
  2. cd للمشروع ثم herdr agent start agy-1 --kind agy --pane wK:p1
    رجع بـ agent_status: idle, cwd: /home/fastfree/Desktop/fastfree. Antigravity اتفتح بـ Gemini 3.8 Flash (High).
  3. herdr agent prompt
    بعتّله الـ 2 bugs المفتوحين في شاشة Machines: العربي مش بيترندر، والـ hydration مش بيحصل.
  4. herdr agent send-keys — الرد على الـ permissions
    وقف 3 مرات على 'Requesting permission' (tail, ps, systemctl). Herdr بيعمل ده agent_blocked — وده بالظبط الـ use case بتاعه: تعرف الوكيل واقف محتاجك.

    أول lead كان 'missing function tAr within MainLayout'. يعني شغال صح في الكود.

3. rea.tools — ظننت إنه UI testing، لأ

REA = Reverse Engineering for your Coding Agent. مش أداة اختبار UI. هي بتدّي الـ agent أدوات تفحص binaries و executables و websites — إزاي الشغّال، إيه الـ connections، إيه الـ strings — من غير ما يشغّل البرنامج. Providers بتاعتها: Ghidra, Hopper, IDA للـ native binaries، ومعاهم CDP browser provider للـ webpages.

الـ CLI موجود — 6.4.0

فحصته بـ npx rea-agents@latest doctor. النتيجة: healthy: false — مفيش registration في opencode ولا antigravity ولا gemini، ومفيش skill متسطب. يعني حتى لو ثبّته، أنا مش هقدر أستخدمه.

REA عندها browser guide: بتفتح Chrome بـ remote-debugging-port، وبعدين inspect-web-page على target معيّن — بترجع accessibility text + network activity + script sources. فتحت Chromium على البانل بالـ CDP وبعتّله الـ target، بس الـ observation failed لأن الـ host check بيفشل على NixOS. الـ CLI موجود والـ MCP متسطب، بس محتاج إعادة تشغيل opencode.
