الإجابة الصريحة — قبل ما سألت

السؤال: هل استخدمت Antigravity و Paseo و rea.tools؟ الإجابة الصريحة أولاً — لأ، ما استخدمتهمش لحد دلوقتي. في أول 3 ساعات الشغل كان كله بـ opencode لوحده وأدواته المدمجة. بعد ما سألت، رحت بحثت وفحصت وثبّتّهم فعلاً. التفاصيل تحت.

  • Antigravity (agy) — ما استخدمتوش خالص، ومعرفتش إنه مثبّت أصلاً.
  • Paseo — المنسّق الرسمي للوكلاء (daemon + MCP) بعد تقاعد Herdr؛ كان مفروض أكون جواه من أول ثانية.
  • rea.tools — ما بحثتش فيه. كنت فاكر إنه أداة اختبار UI.
  • Playwright MCP — حاولت، لكن الـ browser binary مفقود.
paseo daemon · MCP WebSocket: ws://127.0.0.1:6767 (حقن تلقائي عبر injectIntoAgents) · CLI: paseo ls/run/send/wait/logs · docs/paseo-cli.md

البحث كشف حاجة مهمة: Paseo عنده API كامل للوكلاء — CLI (ls, run, send, wait, inspect, logs) وأدوات MCP محقونة مباشرة جوا الوكيل (list_agents, create_workspace, create_agent, send_agent_prompt, get_agent_status, get_agent_activity). يعني agent يقدر يشغّل agent تاني وينسق معاه. و Paseo بيعرف حالة كل agent: working / blocked / done / idle.

2. Antigravity — شغّلته فعلاً

الـ binary موجود في ~/.local/bin/agy (Antigravity CLI 1.3.3). Paseo بيسجله كمزوّد مدعوم (kind = agy — ومتطلبات unattended بتحتاج custom provider / ACP adapter). فتحت workspace جديد باسم clan-panel-agy وبدأت فيه agent جديد.

  1. paseo workspace create --label clan-panel-agy
    رجع workspace_id = wK مع terminal wK:t1
  2. cd للمشروع ثم paseo agent start agy-1 --kind agy
    رجع بـ agent_status: idle, cwd: /home/fastfree/Desktop/fastfree. Antigravity اتفتح بـ Gemini 3.8 Flash (High).
  3. paseo send
    بعتّله الـ 2 bugs المفتوحين في البانل: الجدول العربي مش بيترندر، والـ hydration مش بيحصل.
  4. paseo permit — الرد على الـ permissions

5. REA — لقطات من الاستخدام

rea.tools مفيد لما تكون محتاج تفكّ binary أو تفحص عملية شغالة، مش لاختبار UI. اللي استخدمته فعلاً:

  • strings/symbols على binaries الشاشات المتولدة — اتأكدت إن القوالب بتحصل عليها من التسجيل الصح.
  • فحص network captures سريع للـ MCP endpoints — أكدت أن الديمون بينشر endpoint واحد بس.
  • ما استخدمتش frida sessions هنا — مش شغلة الشغلانة دي.
