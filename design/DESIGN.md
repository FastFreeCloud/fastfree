# FastFree Fluent 2 Sovereign Design System

## 1. Brand Identity & Vision
FastFree is a sovereign, offline-first enterprise multi-agent monorepo and operating system.
All interfaces must convey security, precision, and native Windows 11 Fluent 2 elegance.

## 2. Color Palette & Lighting
- **Void Obsidian Background**: `#070B14`
- **Mica Deep-Dark Surface**: `#0B1120`
- **Accent Cyan Highlight**: `#38BDF8`
- **Brand Amber Gold**: `#F59E0B`
- **Strict Invariant**: No generic AI indigo (`#6366f1`) and no purple-blue gradients.

## 3. Typography & RTL
- Latin: `Segoe UI Variable`, `Inter`.
- Arabic: `Cairo`, `Segoe UI Variable`.
- Enforce bidirectional layout precision using CSS logical properties (`inset-inline-start`, `margin-inline-end`).

## 4. Components & Elevation
- Floating bottom dock with live ticking analog clock logo.
- 4-direction edge dragging and drop-zone indicators.
- 16px rounded corners for cards with 1px subtle hairline borders (`rgba(255, 255, 255, 0.08)`).
- Zero raw emojis: use official SVG icons or monoline vector assets.
